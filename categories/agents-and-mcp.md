# 🤖 Agents & MCP

_MCP servers, agent frameworks and plugins._

- **[awesome-llm-apps](https://github.com/shubhamsaboo/awesome-llm-apps)** ![starter](https://img.shields.io/badge/starter-fb8500?style=flat-square) ![python](https://img.shields.io/badge/python-3776ab?style=flat-square)<br>
  Collection of 100+ open-source AI agents, agent skills and RAG apps you can clone and run.<br>
  🏷 `ai-agents` `rag` `llm-apps` `templates`
- **[claude-mem](https://github.com/thedotmack/claude-mem)** ![plugin](https://img.shields.io/badge/plugin-bf3989?style=flat-square) ![node](https://img.shields.io/badge/node-339933?style=flat-square)<br>
  Plugin that captures what your coding agent does, compresses it and injects relevant context into future sessions.<br>
  🏷 `ai-memory` `claude-code` `context` `agents`
- **[Firecrawl](https://www.firecrawl.dev/)** ![web-tool](https://img.shields.io/badge/web--tool-4f46e5?style=flat-square)<br>
  Web data API that lets AI agents search, scrape, map and crawl the web. The core is open source.<br>
  🏷 `web-scraping` `ai-agents` `api` `crawler`<br>
  💰 freemium
- **[FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi)** ![app](https://img.shields.io/badge/app-1f883d?style=flat-square) ![node](https://img.shields.io/badge/node-339933?style=flat-square)<br>
  Gateway that puts many free LLM provider tiers behind one OpenAI-compatible endpoint, with routing and failover. Personal use only.<br>
  🏷 `llm-gateway` `free-llm` `openai-compatible` `routing`
- **[Headroom](https://github.com/headroomlabs-ai/headroom)** ![library](https://img.shields.io/badge/library-0a7ea4?style=flat-square) ![python](https://img.shields.io/badge/python-3776ab?style=flat-square)<br>
  Compresses tool outputs, logs, files and RAG chunks before they reach the LLM. Works as a library, proxy or MCP server.<br>
  🏷 `context-compression` `token-optimization` `proxy` `mcp`
- **[MiniMax](https://www.minimax.io/)** ![website](https://img.shields.io/badge/website-218bff?style=flat-square)<br>
  AI lab and platform offering multimodal models for text, video, speech and music, with an API and coding and design agents.<br>
  🏷 `llm` `multimodal` `ai-api` `agents`
- **[OmniRoute](https://github.com/diegosouzapw/OmniRoute)** ![app](https://img.shields.io/badge/app-1f883d?style=flat-square) ![node](https://img.shields.io/badge/node-339933?style=flat-square)<br>
  Free open-source AI gateway: one endpoint for many providers and models, with quota-aware auto-fallback.<br>
  🏷 `ai-gateway` `llm-proxy` `model-routing` `mcp`
- **[OpenClaw](https://openclaw.ai/)** ![app](https://img.shields.io/badge/app-1f883d?style=flat-square) ![node](https://img.shields.io/badge/node-339933?style=flat-square)<br>
  Open-source AI assistant that runs on your machine and works from WhatsApp, Telegram or any chat app.<br>
  🏷 `ai-assistant` `agent` `self-hosted` `chat`
- **[OpenRouter](https://openrouter.ai/)** ![web-tool](https://img.shields.io/badge/web--tool-4f46e5?style=flat-square)<br>
  One API and interface for hundreds of AI models, with price and provider comparison and some free models.<br>
  🏷 `llm-api` `model-router` `ai-models`<br>
  💰 freemium
