## Security Testing

- **[Grim Prompter](https://github.com/jmanico/grim-prompter)** <img align="absmiddle" alt="skill" src="https://img.shields.io/badge/skill-d97757?style=flat-square"><br>
  Skill and prompt set that has Claude Code, Codex or another coding agent build an evidence-traced threat model of your repo, with 36 architecture workflows.<br>
  🏷 `threat-modeling` `appsec` `claude-code` `claude-skills`
- **[PentAGI](https://github.com/vxcontrol/pentagi)** <img align="absmiddle" alt="app" src="https://img.shields.io/badge/app-1f883d?style=flat-square"><br>
  Open-source, self-hosted multi-agent system that plans and runs penetration tests with 20+ tools in a Docker sandbox, for authorized testing only.<br>
  🏷 `security` `pentesting` `ai-agents` `self-hosted`<br>
  💰 free
- **[Sherlock](https://github.com/sherlock-project/sherlock)** <img align="absmiddle" alt="app" src="https://img.shields.io/badge/app-1f883d?style=flat-square"><br>
  Command-line tool that checks hundreds of social networks for accounts matching a username, used for OSINT and reconnaissance.<br>
  🏷 `social-media` `username-search` `cli`
